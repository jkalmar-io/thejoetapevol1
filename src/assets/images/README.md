# Images

Asset files for The Joe Tape Vol. 1.

| File | Usage |
|------|-------|
| `cd.png` | CD disc (title slide foreground) |
| `toptape.png` | Top masking tape label |
| `bottomtape.png` | Bottom masking tape label (`Vol. 1`) |
| `wave.gif` | Title slide animated wave background |

PNG assets with black backgrounds use `mix-blend-mode: screen` so they composite cleanly over the wave.
