# Fonts

Drop your font files here (`.woff2` preferred, `.woff` also works).

Then declare them in `src/styles/fonts.css` and update the `--font-display` / `--font-serif` variables in `global.css`.

Example file names:

```
Syne-Regular.woff2
Syne-Bold.woff2
InstrumentSerif-Regular.woff2
InstrumentSerif-Italic.woff2
```
